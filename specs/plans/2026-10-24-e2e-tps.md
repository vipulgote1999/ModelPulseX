# End-to-End TPS Implementation Plan

> **For the executor:** Execute this plan task by task with TDD. Every code step
> has a test that must fail first. Never skip a failing-test run. Commit after
> every task. Record each task in the SDD ledger before starting the next.

**Spec:** `specs/e2e-tps-2026-10-24.md` (approved 2026-10-24 — binding authority)
**Goal:** Add `e2e_tps` (whole-request throughput) alongside the existing decode
`tps`, make end-to-end the only ranked throughput metric, and label both
everywhere the dashboard shows throughput.
**Architecture:** Store `e2e_tps` per run → aggregate hourly/10-minute medians →
carry through `leaderboard_snapshot` → expose as `e2e_tps_*` / `median_e2e_tps`
→ render both metrics with exact labels. Existing `tps_*` fields stay decode.
**Tech stack:** TypeScript 5.7 strict, Cloudflare Workers, D1, Hono, React 18,
Vite, Tailwind, Recharts, Vitest.

## Global Constraints

- Work from the repository root. All commands below assume it.
- Follow `CONVENTIONS.md`. `tps` remains generation-window decode TPS. Never
  write `e2e_tps` into `tps`, and never use total duration for `tps`.
- `e2e_tps = output_tokens / ((completed_at − started_at) / 1000)`, rounded to
  two decimals. Null unless `SUCCESS`, tokens > 0, both timestamps present,
  and elapsed > 0. No floor, no clamp.
- `MIN_SAMPLES = { w1h: 2, w24h: 3, w7d: 5 }` gates every displayed window.
- Decode never ranks. End-to-end drives Overall Score, `sort=tps`,
  `fastest_now`, `best_tps`, and compare's winner.
- All existing `tps_*` API fields keep their exact decode meaning.
- Exact UI strings: `Decode TPS (excludes TTFT)`,
  `End-to-end TPS (includes TTFT)`, `Block delivery`.
- Migration is additive only. No table rebuilds and no new indexes.
- No fabricated data. Missing values stay `null`; old overlay entries without
  `e2e` show no end-to-end value.
- Do not touch unrelated dirty files already present in the main worktree.
- Preflight is `npm test && npm run typecheck && npm run lint`. It must be green
  before the branch is called done.
- `npm run deploy` does not build. A deploy requires `vite build` first.
