### Browser smoke (gate 8) detail

Fails when the dashboard breaks — each case is a real assertion, not a screenshot diff:

1. dashboard loads (title + "LLM PERFORMANCE OBSERVATORY" header, no console/page errors)
2. leaderboard renders one row per model, TPS value comes from the served payload
3. freshness banner shows **LIVE** when `meta.is_stale` is false
4. freshness banner shows **STALE DATA** when `meta.is_stale` is true (truthfulness both ways)
5. an SSE `benchmark.completed` broadcast triggers a leaderboard refetch (honours the
   deliberate 10 s client debounce)

One console line is allowlisted by exact message: the browser's own notice that
`frame-ancestors` is ignored when delivered via `<meta>` (a CSP-meta limitation, not a
dashboard failure). It is reported in the run summary as `ignored 3 browser CSP meta notice(s)`.
